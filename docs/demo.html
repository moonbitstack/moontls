The demonstration

Nothing on this page re-reads a protocol in JavaScript. Both panels call docs/engine/moontls.js, which the documentation build compiles from this repository's source, so an octet the page gets wrong is an octet the library gets wrong.

01 00 05 b5A ClientHello, decoded

Paste a ClientHello — the whole record, header and all, or the handshake message alone — and read what the decoders make of it: the frozen version, the suites by their registry names, and one line per extension with what its bytes actually say. The example is a ClientHello this library wrote, with a post-quantum key share and two key shares in the first flight.

02 00 00 00A handshake, message by message

A client and a server made here, in this tab, with no socket between them: each flight is handed to the other end and every handshake message in it is named as it passes. The walk goes through the QUIC seam, which hands back whole handshake messages at the level of the CRYPTO frame that would carry them — the same messages a record layer would hide under ciphertext.
